# ProactiveMod 再現アドオン

## 概要

本アドオンは、Shu3様が制作されたMinecraft Java Edition（バージョン1.6.4）向けMod「Proactive Mod」を、Minecraft Bedrock Edition向けに再現したアドオンです。

本家Modの特徴的な要素をBedrock Editionで楽しめるよう、アドオンとして再現・調整しています。
